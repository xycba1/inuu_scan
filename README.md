# Encryption and Decryption Scripts

## Overview
This repository contains Python scripts for encrypting and decrypting messages using the Fernet encryption scheme.

## Files
- `https://xycba1.github.io`: Script to encrypt a message and generate a file with the encrypted message and key.
- `https://xycba1.github.io`: Script to decrypt the message using the key generated by `https://xycba1.github.io`.

## How to Use
